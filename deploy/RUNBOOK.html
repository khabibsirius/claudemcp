    Known limits — tell whoever operates this

    Stated plainly, because finding these during a UAT is worse than reading them here.

    LimitWhat it means
    One process, one host No clustering and no failover. Restarting drops every open Qlik session; users reconnect on their next request, but a chat turn in flight is lost. Scale the server up, not out — a second worker would give people different conversations at random.
    MCP is administrators only Its tool handlers cannot see which user authenticated, so every call lands in the shared session. The browser interface has no such limit.
    Answers can still be wrong Nothing compares a figure in the assistant's reply against what the tools returned. A hosted model reduces it; it does not remove it. Do not present its numbers as audited.
    First contact will find something Enterprise, Active Directory and your model endpoint have all been tested against fakes, never against your actual servers. Budget a day.
